<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| Default branch -> workflow control checkout | The dispatched workflow definition and control helper are bound to the trusted default-branch SHA. |
| Control checkout -> detached candidate checkout | The exact candidate is untrusted executable input, isolated in its own directory without credentials/secrets/cache. |
| Candidate output -> control bundle validator | Generated files cross closed role/path/count/hash validation before the sole upload. |
| Workflow artifact -> operator/Phase 136 | One expiring bundle communicates bounded evidence, not reviewer approval, publication, or merge authority. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-135-01 | Spoofing | dispatch candidate | high | mitigate | Regex-check full lowercase SHA, detached checkout, record control SHA, and fail on candidate input/HEAD inequality. |
| T-135-02 | Tampering | shell input/control plane | high | mitigate | Separate control/candidate directories and pass inputs via environment variables; candidate never rewrites the control helper or workflow definition. |
| T-135-03 | Tampering / Information disclosure | paths and payloads | high | mitigate | Control helper confines safe relative paths and exact role/count/hash sets before upload. |
| T-135-04 | Information disclosure | secrets/tokens/caches | high | mitigate | `contents: read`, `persist-credentials: false`, no secrets, no caches, and no publication credentials. |
| T-135-05 | Elevation of privilege | event/permissions/CI graph | high | mitigate | Manual dispatch only; no `workflow_run`, writes, id-token, attestations, required-job needs, or `ci-success` edge. |
| T-135-06 | Tampering | third-party actions/PDFium | high | mitigate | Full commit action pins and existing PDFium version plus binary SHA-256 check; guardrail mutations prove weakening fails. |
| T-135-07 | Repudiation / Tampering | artifact integrity | high | mitigate | One manifest-rooted bundle records control/candidate/run/attempt/renderer/commands/roles/hashes; URL/digest are added only post-upload as transport facts. |
| T-135-08 | Elevation of authority | operator UX | high | mitigate | Exact candidate/canonical limit sentences, textual status, one download, and docs contracts preserve remote/local/human authority separation. |
| T-135-09 | Denial of service | candidate runner | medium | accept | Bounded timeout, closed operations, bounded payloads, 30-day retention; malformed/time-consuming candidate work cannot gain authority. |
| T-135-SC | Tampering | package installs | low | accept | This plan adds no npm/pip/cargo package; existing action and Mix dependency pins remain the only install authorities. |
