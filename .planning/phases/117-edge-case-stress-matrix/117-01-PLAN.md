<objective>
Implement the shared, un-gated byte-golden assert/bless helper (`Rendro.Test.Golden`) that every `:applies` cell in the family x stress-dimension matrix (117-04) and every curated raster fixture (117-06) will call. This is the D-03/D-04 "one bless idiom family" foundation: `assert_deterministic!/1` (two-run determinism pre-check) and `assert_or_bless/3` (SHA-256 compare-or-bless with a hard-flunk on a missing ref, never a silent auto-create).

Purpose: Centralize the golden bless/assert mechanics in one tested module so 117-04's 62 golden test cases and 117-06's 6 raster fixtures share one failure-message doctrine ("a hash change is a DEFECT, not a refresh, unless a human re-authorizes it") instead of each reinventing it.
Output: `test/support/golden.ex` (`Rendro.Test.Golden`, `@moduledoc false`) with `assert_deterministic!/1` and `assert_or_bless/3`; `test/support/golden_test.exs` self-testing both functions in isolation (mirroring the existing `test/support/hex_build_cache_test.exs` sibling pattern).
</objective>

## Artifacts this phase produces (this plan's share)

- `Rendro.Test.Golden.assert_deterministic!/1` -- `@spec assert_deterministic!(Rendro.Document.t()) :: binary()`. Renders `doc` twice with `deterministic: true`, asserts the two binaries are byte-equal, returns the PDF bytes.
- `Rendro.Test.Golden.assert_or_bless/3` -- `@spec assert_or_bless({atom(), atom()}, binary(), keyword()) :: :ok`. `opts[:base_dir]` defaults to `"priv/goldens"` (production default; tests override it to a scratch dir so self-tests never write into the real committed golden tree). `Rendro.Test.Golden` has no `priv/public_api.json` surface (it is test-only code under `test/`, never shipped).
