<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| caller configuration → preset resolver | Untrusted programmer-supplied atoms, keyword keys, modes, densities, and colors enter a public API. |
| vendored release asset → TTF parser/package | Upstream binary bytes become shipped package resources and parser input. |
| document → font registry | Caller-owned registrations share the logical-role namespace with Rendro-curated descriptors. |

## STRIDE Threat Register (ASVS L1; block on high)

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-125-01 | Denial of service | TTF preflight/subsetter | high | mitigate | Vendored-only static faces; verify supported sfnt, `glyf`/`loca`, cmap/metrics, embedding flags, parser success, and bounded deterministic tests before packaging. |
| T-125-02 | Tampering | `priv/fonts` / NOTICE | high | mitigate | Official immutable release URL + tag + commit + member + computed SHA-256 per face, positively matched by tests and Hex archive inspection. |
| T-125-03 | Tampering | `register_fonts/2` | high | mitigate | Compare existing descriptor with exact curated descriptor; identical is idempotent, unequal collision raises without overwrite. |
| T-125-04 | Repudiation | provenance record | medium | mitigate | Face-specific delimited NOTICE blocks and package tests preserve an auditable asset trail. |
| T-125-05 | Information disclosure | error messages | low | accept | Errors expose supplied atoms/values and canonical next action but no secrets; asset-loader internals are excluded per D-04. |
</threat_model>
