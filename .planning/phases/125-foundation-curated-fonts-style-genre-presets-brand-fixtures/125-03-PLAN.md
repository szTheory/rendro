<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| JSON fixture → generic loader/schema | Package data is decoded and later consumed by recipe/catalog code. |
| brand logo reference → package filesystem | A fixture-controlled relative path selects a local asset. |
| synthetic content → public example corpus | Example prose/data can accidentally contain sensitive or misleading real-world identity. |

## STRIDE Threat Register (ASVS L1; block on high)

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-125-11 | Elevation of privilege | logo/fixture paths | high | mitigate | Validate safe-relative paths, resolve within each fixture directory, forbid external references, and reuse `Path.safe_relative/1` behavior. |
| T-125-12 | Tampering | brand identity tuples | medium | mitigate | Strict generic schema, exact D-22 assertions, unique `(domain, slug)`, and unchanged old-fixture hashes. |
| T-125-13 | Information disclosure | synthetic fixture content | high | mitigate | Use invented organizations/persons/account references only; explicit review prohibition and tests for credential/payment-key patterns where defensible. |
| T-125-14 | Denial of service | SVG assets | medium | mitigate | Tiny deterministic geometry-only local SVGs; reject scripts, external refs, embedded images, gradients, filters, and text. |
| T-125-15 | Repudiation | arithmetic fixtures | medium | mitigate | Decimal-string schema and exact domain reconciliation tests make authored totals auditable. |
</threat_model>
