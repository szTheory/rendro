    - Steps: `actions/checkout` (with current SHA), `erlef/setup-beam` (with current SHA), `sudo apt-get install -y poppler-utils`, `mix deps.get`.

    - Run `mix ci` and `mix release.preflight` without the `HEX_API_KEY` (since it's scoped to the environment later).

    - Explicitly set `environment: 'Hex Publish'`.
    - Steps: `actions/checkout`, `erlef/setup-beam`, `mix deps.get`.
    - Add the actual `mix hex.publish --yes` step supplying the `HEX_API_KEY` via environment secrets: `env: HEX_API_KEY: ${{ secrets.HEX_API_KEY }}`.
