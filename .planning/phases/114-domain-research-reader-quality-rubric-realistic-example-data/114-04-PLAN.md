|----------|--------------|
| `Rendro.Examples.load!/1` / `list/1` argument | The only place in this phase where a string parameter is joined into a filesystem path before a read. `@moduledoc false` means this is never part of the public API surface — every current call site (tests, bench scripts, future guides/Livebook) passes a hardcoded literal string, never external input. |

| T-114-04-01 | Tampering / Information Disclosure | `Rendro.Examples.load!/1`'s `relative_path` parameter | medium | mitigate | `load!/1` resolves `relative_path` under `Application.app_dir(:rendro, "priv/examples")` only after `Path.safe_relative/1` accepts it, raising `ArgumentError` on any `../`-style escape attempt before `File.read!` ever runs. The module keeps the exact `load!(relative_path :: String.t())` signature specified in 114-RESEARCH.md/114-PATTERNS.md (not an enumerated-atom signature) since every current caller is internal/hardcoded and real exploitability is nil this milestone; the guard is defense-in-depth against a hypothetical future indirect exposure (e.g. Milestone C's public catalog). |
