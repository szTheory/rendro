<objective>
Normalize the de-quarantined invoice fixture's money fields from integer cents (`price_cents`, `subtotal_cents`, `tax_cents`, `total_cents`) to Decimal-safe 2-decimal strings (`price`, `subtotal`, `tax`, `total`), add the S4 optional empty `brand`/`logo` slot, and update all four scripts that read the fixture's money fields so nothing breaks — as a commit **separate** from Plan 114-01's verbatim move (per RESEARCH.md Pitfall 6). Then author `test/docs_contract/examples_schema_contract_test.exs`, the first real consumer of Plan 114-02's schema, proving every fixture under `priv/examples/` validates.

Purpose: EXL-01 requires money-as-strings and EXL-06 requires the brand/logo seam on every fixture; EXL-03 requires an automated schema-validation lane. This plan delivers all three while proving — via the same byte-diff mechanism Plan 114-01 used — that the normalization does not silently change what Rendro itself renders (Phase 115, not this phase, is responsible for wiring `Decimal`/`Rendro.Format.money/1` into the actual `Rendro.Recipes.Invoice` module).
Output: a normalized fixture, four updated bench consumer scripts, and a new schema-contract test file.
</objective>
