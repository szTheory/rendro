<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| raw local/CI output -> normalized snapshot | Untrusted or expiring output crosses into committed evidence facts. |
| local/advisory observation -> authoritative claim | Evidence with weaker authority could spoof primary-CI proof. |
| finding state change -> durable ledger closure | A label or unrelated green result could conceal unresolved risk. |
| raw output -> Git review | Paths, credentials, or sensitive process output could be disclosed. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-132-01 | Tampering / Repudiation | `.planning/quality/baselines/132-initial.json` evidence records | high | mitigate | Require exact source SHA, raw SHA-256, byte count, location, expiry, capture identity, and schema/mutation validation; focused test rejects missing or malformed provenance. |
| T-132-02 | Spoofing | evidence lane and authority fields | high | mitigate | Store explicit `deterministic`, `proof`, `advisory`, or `human_review` lane plus local/primary-CI identity; require unavailable status/reason/trigger when authority is absent. |
| T-132-03 | Tampering | `.planning/QUALITY.md` lifecycle and closure | high | mitigate | Require focused proof, relevant full gate, compatibility evidence, before/after statement, and resolution reference before `closed`; contract test rejects incomplete closure. |
| T-132-04 | Information Disclosure | raw command output | medium | mitigate | Redact before normalization, record redaction class, commit hashes/metadata only, and assert no raw logs/PDFs/PNGs/reports/caches enter Git. |
