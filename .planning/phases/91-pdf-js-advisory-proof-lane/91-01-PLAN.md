<decisions>
- Use a direct Node ESM script rather than a Mix wrapper. This keeps Node clearly outside the Elixir runtime and required `mix ci` lane.
- Use two low-churn committed fixtures: `test/fixtures/embedded_artifact_support_fixture.pdf` and `bench/results/raw/rendro.pdf`.
- Store observations in `priv/pdfjs_observations/` as repo evidence, not Hex package content.
- Keep support matrix unchanged except tests asserting existing PDF.js deferrals remain unchanged.
- Defer PNG hashes for this plan. Metadata observations cover the required contract and avoid native-canvas determinism risk.
</decisions>

<threat_model>
| Threat | Risk | Mitigation |
|--------|------|------------|
| npm package drift changes observations | Medium | Exact `pdfjs-dist` dependency, committed lockfile, and `npm ci` in CI. |
| Node/npm becomes a required dependency | High | Keep tooling in `scripts/pdfjs_observer/` and add guardrail tests banning Node/npm/pdfjs from the required `test` job. |
| PDF.js observations are mistaken for GUI support | High | Use "pinned PDF.js advisory observations"; ban unqualified "PDF.js support"; keep support matrix PDF.js rows as deferrals. |
| Platform data causes CI churn | Medium | `--check` compares stable PDF facts while validating platform metadata exists. |
| PNG hash instability | Medium | Defer PNG hashes until a future deterministic proof path exists. |
</threat_model>
