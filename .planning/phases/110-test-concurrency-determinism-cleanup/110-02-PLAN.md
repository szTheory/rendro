<objective>
Establish a flake quarantine lane, quarantine known flakes, properly layer test suites via ExUnit exclusions, and document testing strategies.

Purpose: Nondeterministic tests must not block PRs via blind retries. We use a `threadline` pattern to isolate them into a nightly `verify.flake` lane where they can be measured and fixed without impacting development speed. Test suite layers must be structurally enforced via `ExUnit.configure` exclusions and slowest tests tracked via the `--slowest` flag. Additionally, we must record our architectural decisions against test partitioning and document why certain tests remain `async: false`.
Output: Updated `mix.exs` aliases, a quarantined `RecipesFacadeDriftTest`, and documented testing guidelines with enforced exclusions in `test_helper.exs`.
</objective>
