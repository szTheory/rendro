<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| manifest record -> filesystem | Untrusted record paths could escape the capsule or substitute a file. |
| retained source -> durable capsule | Historical facts, provenance, or redaction state could be altered during import. |
| capsule role -> release/proof consumer | A stale/wrong role or mismatched identity could gain operational authority. |
| evidence text -> logs/docs | Secrets, home paths, PIDs/ports, or binary proof bytes could leak. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-133-01 | Tampering / Information Disclosure | manifest traversal and symlink handling | high | mitigate | Reject absolute/unsafe paths, expand under the fixed capsule root, require confinement and a regular non-symlink file before read; mutation tests prove rejection. |
| T-133-02 | Tampering / Spoofing | record identity, role, digest, candidate/tag/version binding | high | mitigate | Strict schemas/enums, uniqueness checks, SHA-256 verification, and cross-record binding all run before facts are returned. |
| T-133-03 | Information Disclosure | imported JSON/Markdown and diagnostics | high | mitigate | Preserve redaction assertions and scan for secret names, local home paths, PID/port data, and PDF bytes; diagnostics name bounded repository paths only. |
| T-133-04 | Elevation of Privilege / Tampering | archived planning becoming executable authority | high | mitigate | Atomic D-06 cutover plus focused active-source scan; only explicitly inventoried `gsd_tooling` may inspect planning structure. |
| T-133-05 | Repudiation | digest presented as independent immutability | medium | mitigate | Record source/import provenance separately and state that Git history, branch controls, and tags are authority per D-13. |

Every high-severity mitigation must have a passing negative-path or focused consumer-scan assertion before this atomic task commits.
</threat_model>
