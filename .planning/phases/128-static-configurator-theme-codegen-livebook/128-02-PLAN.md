## Assumption delta decision

Primary noun: canonical requested configuration/source model (`family`, `preset`, `accent`, `mode`). Decision: no-change. The generated module is an application-owned projection of Plan 01's formatter, not a second configuration identity.

## Flagged edge assumptions

- CONFIG-05 concurrency `If interrupted or run in parallel, what is guaranteed?`: unresolved and explicitly flagged. The accepted contract covers one invocation at a time, pre-write validation, Mix.Generator conflict handling, sole explicit force overwrite, and a mutation-free check path; it makes no multi-process transaction or rollback promise.
