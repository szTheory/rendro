## Trust Boundaries

| Boundary | Description |
|---|---|
| Workflow artifacts -> local validator | Externally produced files and metadata are untrusted until semantic and identity validation succeeds. |
| Git history -> baseline provenance | A commit label is trusted only after its exact manifest blob is compared. |
| Staging -> canonical assets | Publication crosses an all-or-nothing durable-state boundary. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-136-B0 | Spoofing | run/commit/renderer identity | high | mitigate | Full exact identities are cross-bound across every payload and verified before image use. |
| T-136-B1 | Tampering | bundle role payloads | high | mitigate | Closed schemas, safe paths, full digests, exact order/count, and cross-payload joins fail closed. |
| T-136-B2 | Repudiation | baseline ownership | high | mitigate | Git blob bytes must equal the checked-in baseline before its owning full SHA is recorded. |
| T-136-B3 | Information disclosure | artifact paths | medium | mitigate | Reject absolute, traversal, backslash, NUL, duplicate, and out-of-root paths. |
| T-136-B4 | Denial of service | malformed pin/JSON | medium | mitigate | Decode/type failures return bounded structured errors rather than crashes. |
| T-136-B5 | Elevation of privilege | convenience gallery/reviewer state | high | mitigate | Only changed_targets and closed bundles authorize deterministic evidence; gallery and review remain descriptive. |
| T-136-B6 | Tampering | canonical transaction | high | mitigate | Failure-injected two-artifact transaction tests prove complete rollback before backups are removed. |
| T-136-SC | Tampering | package supply chain | low | accept | No package install or dependency change occurs. |
</threat_model>
