<objective>
Close the two verified gaps in Phase 122 (see 122-VERIFICATION.md) without touching the already-VERIFIED no-theme contract.

- **CR-01 (BLOCKER):** Payslip's `typography/1` theme branch returns `Rendro.Theme.resolve(theme).typography` whose `fonts.<role>` are bare `:default` atoms (fallback-less built-in Helvetica). That severs the B612 unicode fallback (`:payslip_unicode_fallback`) carried by `:payslip_sans`, so any themed Payslip crashes on its own canonical data (`{:error, %Rendro.Error{reason: {:unsupported_glyph, "•"}, stage: :measure}}`) — a regression from Phase 121 that would break Phase 123's themed/dark gallery. Fix: remap the theme branch's `fonts` onto the fallback-bearing `:payslip_sans`.
- **WR-01 (WARNING):** Certificate's `body_section/2` hardcodes `Rendro.PDF.Font.helvetica()` for all centering measurement while the emitted `%Text{}` carries `font: font_role`. Under a theme whose font role names a non-Helvetica embedded font the text de-centers silently. Fix: guard the centering path so a non-Helvetica-metric centered font role is rejected honestly (errors-as-product), and correct the now-false comment; the coupling holds for every shipped theme (`default/0` and `from_brand/2` both emit `fonts: :default`).
- **WR-02 (coverage hole):** The themed assertions only compared `sections/2` `%Section{}` structs (refute equality), never `render/2`/`measure_rows/4` — which is exactly why CR-01 passed CI. Add themed end-to-end `Rendro.render` smoke coverage.

Purpose: Deliver the D-02 intent ("seam text→ink NOW so dark/brand just works") for real — a themed Payslip must render its own documented data — and permanently close the render-path coverage hole so this class of regression cannot ship again.

Output: Patched `payslip.ex` + `certificate.ex` (themed branch / centering path only), a themed Payslip render regression assertion, a Certificate centering-coupling + guard test, and a cross-recipe themed render smoke test.
</objective>

This is a local, offline Elixir PDF-generation library. There is **no network surface, no authentication, no session, no persistence, and no external process execution** in scope. Untrusted document data is text that is measured and drawn into a deterministic PDF byte stream; the honest threat surface for this gap-closure is **low/none**, and that is the correct output rather than invented threats.
