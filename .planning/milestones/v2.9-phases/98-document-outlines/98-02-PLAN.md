  <name>Task 1: Add UTF-16BE encoder</name>
  <files>lib/rendro/pdf/writer.ex</files>
  <action>
    In `lib/rendro/pdf/writer.ex`:
    - Add a private helper `utf16be_hex(string)` that converts an Elixir UTF-8 string to UTF-16BE.
    - Prepend the Byte Order Mark (BOM) `<<0xFE, 0xFF>>`.
    - Return `{:hex_string, bom <> utf16_binary}` which is fully supported natively by `Rendro.PDF.Object.serialize/2`.
  </action>
  <verify>
    <automated>mix test --warnings-as-errors</automated>
  </verify>
  <done>The private helper exists and compiles cleanly.</done>
</task>

<task type="auto" tdd="true">
  <name>Task 2: Allocate and serialize outline tree</name>
  <files>lib/rendro/pdf/writer.ex, test/rendro/pdf/writer_test.exs</files>
  <behavior>
    - If `doc.metadata.outlines` is empty, no `/Outlines` is injected into the Catalog.
    - If `outlines` is populated, a valid doubly-linked list (`/First`, `/Last`, `/Parent`, `/Next`, `/Prev`) is built.
    - `page_idx` in destinations correctly maps to the allocated object number.
  </behavior>
  <action>
    In `lib/rendro/pdf/writer.ex`:
    - In `build_objects/4`, if `doc.metadata.outlines` is not empty, allocate a root outline object number and allocate outline items using a helper `allocate_outlines/3`.
    - Outline Item Pointers required:
      - `/Title`: use `utf16be_hex/1`.
      - `/Parent`: object number of the parent (or the root outline dict).
      - `/Next`, `/Prev`, `/First`, `/Last`: corresponding object numbers based on the tree traversal.
      - `/Dest`: translate the logical 1-based `page_idx` into the allocated `page_num`. `page_nums` is a list of `{page_num, content_num}` tuples. You can look it up with `elem(Enum.at(page_nums, page_idx - 1), 0)`. Result: `[{:ref, page_num, 0}, :XYZ, x, y, nil]`.
    - Note on `/Count`: since we don't strictly require explicit expand/collapse behavior to be hardcoded, you can omit `/Count` from outline items (which defaults to 0 descendants visible, i.e., collapsed).
    - Accumulate the allocated dictionaries and ensure they are added to `numbered_objects`.
    - Inject the root Outline dictionary number into the `catalog_dict` as `{"Outlines", {:ref, outlines_num, 0}}`.
  </action>
  <verify>
    <automated>mix test test/rendro/pdf/writer_test.exs</automated>
  </verify>
  <done>Writer natively emits the correct doubly-linked structure with correct strings and destinations.</done>
</task>
