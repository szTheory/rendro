<task type="auto" tdd="true">
  <name>Task 2: Harvest outlines in Paginate</name>
  <files>lib/rendro/pipeline/paginate.ex, test/rendro/pipeline/paginate_test.exs</files>
  <behavior>
    - Blocks with `outline: true` extract text from `%Rendro.Text{}` or `%Rendro.Pipeline.MeasuredText{source: %Text{}}`.
    - Blocks with `outline: string` use the string directly.
    - Flat harvested lists are folded into a nested tree based on `outline_level`.
    - Skipped levels (e.g. 1 followed by 3) attach the child to the last known parent gracefully.
  </behavior>
  <action>
    In `lib/rendro/pipeline/paginate.ex`:
    - Follow the pattern of `collect_anchors/1` to add `collect_outlines/1` (called in the main `Paginate.run` pipeline).
    - Iterate over `doc.pages` (with 1-based `page_idx`) and `page.blocks`.
    - When `block.outline` is truthy, determine the title. If extraction fails for `outline: true` on complex blocks, fallback to `"Section"` or skip it gracefully.
    - The destination format must be: `[page_idx, :XYZ, block.x || 0, block.y || 0, nil]`.
    - Collect these into a flat list of `%{title: string, level: int, dest: list}` in order of appearance.
    - Implement a pure-functional stack-based tree folder (`build_outline_tree/1`) that takes the flat list and returns a list of root nodes: `[%{title: string, dest: list, children: [...]}]`.
    - Store the resulting tree in `doc.metadata.outlines`.
  </action>
  <verify>
    <automated>mix test test/rendro/pipeline/paginate_test.exs</automated>
  </verify>
  <done>Paginate accurately extracts text and constructs a correct hierarchical tree in metadata.</done>
