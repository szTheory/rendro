Brand DNA

A native document engine you can reason about and operate

Rendro turns Elixir data into reliable documents — composable in code, predictable in layout, observable in production, and honest about limits. Quieter than a SaaS startup, warmer than a systems library, more precise than a design tool.

Essence
A native Elixir document engine you can reason about and operate.
Audience
Phoenix/Elixir engineers shipping business documents in production — invoices, statements, receipts, certificates, reports.
Technical promise
Composable in code, predictable in layout, observable in production, honest about limits.
Visual metaphor
Structured flow — content becoming a reliable document through frames, baselines, and pagination. Not printing; not browser rendering.
Mantra
Render the document. Respect the system. Explain the failure.
Personality
70% senior open-source maintainer, 20% typographer, 10% SRE. Precise, calm, helpful, native, observable.
Anti-traits
Flashy, mascot-heavy, enterprise, print-shop nostalgic, browser-rendering-disguised-as-native, compliance-overclaiming.
Should never feel like
A commercial PDF SDK, a browser wrapper, or a hype landing page.

Logo

The page-frame R

The mark is a capital R whose bowl is a page with a folded corner; the stem carries a single structural seam and the leg kicks past the baseline — content becoming a finished document. “endro” is built from the same geometric stencil so the R stays the hero. The mark has no bounding box; it sits on the page.

DO

  • Place the mark directly on the page — it has no box by design.
  • Keep the height of the lowercase “n” as clear space around it.
  • Use the self-theming files on light and dark; one-color contexts use rendro-mono.svg.
  • Min sizes: lockup ≥ 96px wide, mark ≥ 24px, favicon ≥ 16px.

DON'T

  • Add a box, plate, gradient, or shadow behind the mark (the avatar fill is the only exception).
  • Recolor the letterforms or make the whole mark blue — the fold is the only accent.
  • Add a subtitle to the primary lockup — use rendro-subtitle.svg.
  • Stretch, condense, rotate, or rebuild “endro” in another typeface.

Voice & tone

A senior maintainer who respects your time

Lead with the concrete. State limits in the same breath as the capability. Explain the failure — never just flag it. Sound like a maintainer, not a marketer. No magic, ever.

SAY THIS

Build PDF documents as Elixir data, then render them with predictable layout and production telemetry.

NOT THIS

Generate perfect PDFs instantly with magical browserless rendering.

SAY THIS

This table row can’t fit the remaining space. Allow row splitting or start it on a new page.

NOT THIS

Layout failed.

SAY THIS

Rendro does not render arbitrary HTML/CSS. Use document components, or an HTML-to-PDF renderer when CSS fidelity is the goal.

NOT THIS

Rendro replaces every PDF tool.

ERROR PATTERN — what / where / why / what next

Table row could not fit the remaining body space.
  Template: MyApp.PDF.Statement
  Region:   :body
  Block:    document.body.table[0].row[112]
  Available height: 16pt   Required height: 40pt
Rendro table rows are atomic and do not split across pages.
Try: start the row on a new page, reduce cell padding, or shorten the cell.
